This project was carried out for a microelectronics course. The goal was to develop a game on an FPGA chip using VHDL and the Quartus software environment.

The system had to communicate with two external devices: a monitor via a VGA cable to transmit video data, and a game controller.

We chose to create a game inspired by Smash Bros., where two players battle each other. Anticipating potential issues with player movement was challenging, and numerous adjustments were made through hands-on testing.
